One line: a one-star review of Monday, written as if Monday were a restaurant — 22 words.

> One star. Ordered the Monday special: cold coffee, stale bread, and a bill for the whole week. The waiter never came back.

## How it works

`main.py` (stdlib only) copies the pre-written review in `entry.txt` into the output directory the grader provides (`MAKEFUN_OUTPUT_DIR`), as `entry.txt`.

## Entry

- Text: `entry.txt` — 22 words, 122 characters, single line, plain text.
- Gate: UTF-8 text, 1–180 characters, not only whitespace.
